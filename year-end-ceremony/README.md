# 🏆 병원 연말 송년의 밤 & 시상식 모션그래픽 스크린

병원/기업 강당 대형 스크린(빔프로젝터, 대형 LED 디스플레이) 송출용 실시간 벡터 모션그래픽 웹페이지 샘플 모음입니다.  
별도의 백엔드 서버나 Node.js 환경 없이 크롬(Chrome)이나 엣지(Edge) 브라우저에서 더블 클릭 후 `F11`(전체화면)만 누르면 칼같이 선명한 고화질로 구동됩니다.

---

## 📂 버전별 파일 안내 (취향에 맞게 선택)

1. **`index.html` / `v3_refined_stage.html` (가장 추천)**
   - **특징**: 배경의 은은한 3D 유기적 점선/파티클 웨이브(Three.js) + 네모박스 모서리를 회전하는 고급스러운 레이저 보더 빔(Border Beam) 탑재.
   - 과하거나 어지러운 조명을 배제하고, 차분하면서도 웅장한 하이엔드 테크/갈라쇼 무대 느낌.

2. **`v2_cinematic_spotlight.html`**
   - **특징**: 방송국 무대 연출 버전. 7초마다 다음 수상자 카드로 가상 스포트라이트 조명이 이동하는 시퀀서 탑재.

3. **`v1_standard.html`**
   - **특징**: 차분하고 단정한 다크 글래스모피즘(유리 질감) 대시보드 버전.

---

## 🌟 공통 핵심 기능

* **실시간 3D 공간 연출 (Three.js WebGL)**: 60fps 무한 루프로 부드럽게 일렁이는 황금빛 파티클 메쉬.
* **올인원 1-화면 레이아웃**:
  - 좌측: 타임라인 형태의 행사 진행 식순 (현재 진행 단계 하이라이트)
  - 우측: 영예의 수상 부문 및 수상자 명단
  - 상단: 실시간 디지털 시계 (초 단위 갱신) & 3D 회전 자이로스코프 엠블럼
  - 하단: ON AIR 오디오 비주얼라이저 & 축하 공지 롤링 티커
* **100% 무설치 & 무손실 벡터 그래픽**: FHD, 4K, 8K 어떤 빔프로젝터 해상도에서도 폰트와 그래픽 깨짐 없음.

## ✏️ 텍스트(식순, 수상자) 수정 방법

각 파일 하단의 `<script>` 태그 내 `ceremonyData` 객체에서 글자만 수정하고 저장(`Ctrl + S`) 후 브라우저에서 새로고침(`F5`)하시면 즉시 반영됩니다.

```javascript
const ceremonyData = {
  title: "2026 연말 송년의 밤 & 의료대상 시상식",
  subtitle: "함께 만든 열정의 발자취, 더 찬란하게 도약할 내일을 향하여",
  
  order: [
    { num: "01", name: "개회 선언 및 국민의례", time: "18:30", active: false },
    ...
  ],

  awards: [
    {
      category: "GRAND PRIX",
      name: "올해의 자랑스러운 의료대상",
      winners: [
        { dept: "심혈관센터", name: "김진우 과장" }
      ]
    },
    ...
  ]
};
```
