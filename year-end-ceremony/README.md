# 🏆 병원 연말 송년의 밤 & 시상식 모션그래픽 스크린

병원/기업 강당 대형 스크린(빔프로젝터, 대형 LED 디스플레이) 송출용 실시간 벡터 모션그래픽 웹페이지 샘플 모음입니다.  
별도의 백엔드 서버나 Node.js 환경 없이 크롬(Chrome)이나 엣지(Edge) 브라우저에서 더블 클릭 후 `F11`(전체화면)만 누르면 칼같이 선명한 고화질로 구동됩니다.

---

## 📂 버전별 파일 안내 (취향에 맞게 선택)

1. **`index.html` / `v4_searchlight_stage.html` (최신 헐리우드 서치라이트 버전, 강력 추천!)**
   * **특징**: 
     - **양쪽 바닥 서치라이트**: 영화제/시상식 오프닝처럼 무대 양쪽 바닥에서 하늘을 향해 대각선으로 교차하며 부드럽게 스윙하는 헐리우드 광원 연출.
     - **몽환적 소프트 사선 반사광**: 카드 표면을 칼같은 선이 아니라 안개처럼 은은하고 부드럽게(16px blur) 스쳐 지나가는 고급스러운 골드 빛무리.
     - **배경 3D 파티클 메쉬**: Three.js 실시간 3D 황금빛 파동 및 네모박스 레이저 보더 빔 유지.

2. **`v3_refined_stage.html`**
   * **특징**: 서치라이트 없이 3D 파티클 메쉬와 박스 레이저 보더 빔 위주의 미니멀 & 럭셔리 스테이지 버전.

3. **`v2_cinematic_spotlight.html`**
   * **특징**: 7초마다 특정 카드가 하이라이트되는 가상 스포트라이트 시퀀서 버전.

4. **`v1_standard.html`**
   * **특징**: 차분하고 단정한 다크 글래스모피즘 대시보드 버전.

---

## ✏️ 텍스트(식순, 수상자) 수정 방법

각 파일 하단의 `<script>` 태그 내 `ceremonyData` 객체에서 글자만 수정하고 저장(`Ctrl + S`) 후 브라우저에서 새로고침(`F5`)하시면 즉시 반영됩니다.
