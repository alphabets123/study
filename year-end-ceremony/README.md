# 🏆 병원 연말 송년의 밤 & 시상식 모션그래픽 스크린

병원/기업 강당 대형 스크린(빔프로젝터, 대형 LED 디스플레이) 송출용 실시간 벡터 모션그래픽 웹페이지 샘플 모음입니다.  
별도의 백엔드 서버나 Node.js 환경 없이 크롬(Chrome)이나 엣지(Edge) 브라우저에서 더블 클릭 후 `F11`(전체화면)만 누르면 칼같이 선명한 고화질로 구동됩니다.

---

## 📂 버전별 파일 안내 (취향에 맞게 선택)

1. **`index.html` / `v5_prestige_stage.html` (최종 완성형 V5, 강력 추천!)**
   * **특징**: 
     - **싼티 없는 샴페인 스파크 VFX**: 유치한 꽃가루 대신, 속도 꼬리를 가진 초미세 샴페인 골드 스파크와 찰나의 십자 스타버스트 탑재.
     - **헐리우드 대각선 서치라이트**: 무대 양쪽 바닥에서 올라와 하늘을 향해 교차하는 웅장한 볼륨메트릭 조명.
     - **3D 프리미엄 아크릴 글래스**: 테두리를 회전하는 레이저 보더 빔 + 안개처럼 부드러운 샴페인 사선 반사광.
     - **프리젠터 단축키 탑재**: 키보드 `→` 또는 `Space` 키를 누르면 다음 식순으로 부드럽게 넘어가며 골드 펄스로 강조!

2. **`v4_searchlight_stage.html`**
   * **특징**: 양쪽 바닥 서치라이트 및 사선 반사광 버전.

3. **`v3_refined_stage.html`**
   * **특징**: 서치라이트 없이 3D 파티클 메쉬와 박스 레이저 보더 빔 위주의 미니멀 버전.

4. **`v1_standard.html`**
   * **특징**: 차분하고 단정한 다크 대시보드 버전.

5. **`kinetic_demo.html` / `tapsonic_top_result.html`**
   * **특징**: 텍스트가 쾅 찍히는 키네틱 모션그래픽 및 탭소닉 게임 스타일 비주얼 실험실 샘플.

---

## ✏️ 텍스트(식순, 수상자) 수정 방법

각 파일 하단의 `<script>` 태그 내 `ceremonyData` 객체에서 글자만 수정하고 저장(`Ctrl + S`) 후 브라우저에서 새로고침(`F5`)하시면 즉시 반영됩니다.
